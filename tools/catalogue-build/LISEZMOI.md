# Fabrication du catalogue (29/10/2026)
Ordre : `pop2.py` (code + popularité de tous les produits Open Food Facts, lecture par plages de l'export Parquet sur Hugging Face) → `det.py` (détails des 10 000 plus populaires) → `ctry2.py` (pays de tous les produits) → sélection par pays (250 par pays pour les 40 plus gros, 100 pour les autres ayant plus de 1 000 produits ; non enregistrée en fichier : voir tools/CATALOGUE.md) → `det2.py` (détails de la sélection) → `build2.py` (filtres de cohérence, dédoublonnage, CSV).
`rf.py` lit le fichier distant par plages et se reconnecte quand le serveur de téléchargement change. L'export change chaque nuit : refaire popularité et pays dans la même session. Chemins : fichiers de travail dans le dossier courant. Licence des données : ODbL 1.0 / DbCL 1.0 (Open Food Facts).
